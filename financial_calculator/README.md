# Calculadora financiera

Resuelve las cuentas de dinero de todos los días: la cuota de un préstamo con su tabla de amortización, el interés simple y compuesto, el ahorro con aportes mensuales y la conversión entre tasas. Las tasas se escriben como efectivas anuales, como se publican en Colombia, y los valores van en pesos colombianos. No usa servidor ni cuentas: lo único que recuerda son los últimos valores escritos.

## Ejecución local

Desde esta carpeta:

    python ../dev_server.py

Abrir http://localhost:8080 en el navegador.
