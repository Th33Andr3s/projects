# Generador aleatorio

Deja el azar decidir de forma justa: saca números en un rango (con o sin repetir), elige a alguien de una lista, mézclala o repártela en equipos, y tira dados de 4 a 100 caras o monedas. El resultado sale en letras grandes, se puede copiar, y un historial guarda las últimas tiradas por si alguien pregunta quién salió antes. Pensado para rifas, sorteos de turnos y armar equipos desde el computador o el celular. Usa el generador de azar del sistema (no `Math.random`) y no usa servidor ni cuentas: nada de lo que se escribe sale del navegador.

## Ejecución local

Desde esta carpeta:

    python ../dev_server.py

Abrir http://localhost:8080 en el navegador.
