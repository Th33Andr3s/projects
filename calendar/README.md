# Calendario

Agenda personal: un calendario de mes donde se anotan eventos por día, con repeticiones (cada semana, mes o año) y los festivos de Colombia ya marcados. Una lista de próximos eventos muestra lo que viene. No usa servidor ni cuentas: los eventos se guardan solo en este navegador, y se pueden descargar como respaldo (Exportar) y cargar de nuevo en otro equipo (Importar).

## Ejecución local

Desde esta carpeta:

    python ../dev_server.py

Abrir http://localhost:8080 en el navegador.
