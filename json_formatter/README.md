# Formateador de JSON

Pega un JSON y déjalo legible: lo formatea con sangría o lo minifica, avisa en qué línea y columna está el error cuando no es válido, permite ordenar las claves y deja copiar o descargar el resultado. Pensado para quien trabaja con respuestas de una API o archivos de configuración. No usa servidor ni cuentas: nada de lo que se pega sale del navegador.

## Ejecución local

Desde esta carpeta:

    python ../dev_server.py

Abrir http://localhost:8080 en el navegador.
