# Calculadora de materiales

Calcula cuánto material comprar para una obra pequeña: los ladrillos y el mortero de un muro, el cemento, la arena y la grava del concreto, el pañete y la pintura de unas paredes, y la baldosa, el pegante y la boquilla de un piso. Usa las presentaciones que se venden en Colombia (bultos, metros cúbicos, galones, cajas) y permite copiar la lista de compras. No usa servidor ni cuentas: lo único que recuerda son los últimos valores escritos.

## Ejecución local

Desde esta carpeta:

    python ../dev_server.py

Abrir http://localhost:8080 en el navegador.
