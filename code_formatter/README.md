# Formateador de código

Pega CSS, HTML o SQL y déjalo ordenado: lo formatea con sangría o lo minifica, avisa de una llave, una etiqueta o un paréntesis sin cerrar con su línea, y deja copiar o descargar el resultado. Detecta el lenguaje solo, y para cualquier otro texto limpia los espacios sobrantes. Pensado para quien copia un estilo, una consulta o un trozo de HTML y necesita leerlo o pegarlo limpio. No usa servidor ni cuentas: nada de lo que se pega sale del navegador.

## Ejecución local

Desde esta carpeta:

    python ../dev_server.py

Abrir http://localhost:8080 en el navegador.
