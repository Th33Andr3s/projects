# Generador de contraseñas

Genera contraseñas seguras al azar, con la longitud y los tipos de caracteres que la persona elija, y las copia al portapapeles con un toque. Está pensado para usarse desde el celular en el momento en que una aplicación pide una contraseña nueva. No guarda ninguna contraseña: lo único que recuerda son las opciones elegidas.

## Ejecución local

Desde esta carpeta:

    python ../dev_server.py

Abrir http://localhost:8080 en el navegador.
