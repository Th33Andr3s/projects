# Comparador de textos

Pega dos textos y mira qué cambió: las líneas quitadas, las agregadas y, dentro de cada línea modificada, las palabras distintas. Se puede ver todo seguido o las dos versiones lado a lado, esconder lo que no cambió, saltar de cambio en cambio, ignorar espacios o mayúsculas, y copiar o descargar el resultado como diff, el formato que entienden Git y los editores. Pensado para quien tiene dos versiones de un contrato, un correo, una configuración o un trozo de código y necesita saber qué cambió sin leerlo todo dos veces. No usa servidor ni cuentas: nada de lo que se pega sale del navegador.

## Ejecución local

Desde esta carpeta:

    python ../dev_server.py

Abrir http://localhost:8080 en el navegador.
