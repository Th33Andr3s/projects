# Libro de vida

Libro digital privado de una pareja. Cada uno escribe desde el celular lo que vivió, con fotos si quiere, y las páginas se leen como un libro físico con estrellas y animaciones. Todo el contenido vive en Supabase y solo se ve tras iniciar sesión. Si el proyecto gratuito de Supabase pasa 7 días sin actividad, se pausa y hay que reactivarlo desde su panel.

## Ejecución local

Desde esta carpeta:

    python ../dev_server.py

Abrir http://localhost:8080 en el navegador.
