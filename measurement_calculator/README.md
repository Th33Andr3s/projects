# Calculadora de medidas

Convierte al instante un valor entre unidades de medida: longitud, masa, volumen, temperatura, área, tiempo, cocina, velocidad, datos, energía y presión. Está pensada para resolver la duda del momento desde el celular, sin leer instrucciones. No usa servidor ni cuentas: lo único que recuerda es la última conversión.

## Ejecución local

Desde esta carpeta:

    python ../dev_server.py

Abrir http://localhost:8080 en el navegador.
