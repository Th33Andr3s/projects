# Lista de tareas

Anota lo que hay que hacer, con fecha límite, prioridad y una nota si hace falta, y míralo agrupado por cuándo toca: vencidas, hoy, mañana, esta semana, más adelante y sin fecha. Marca las tareas como hechas, edítalas, bórralas con la opción de deshacer, búscalas y haz un respaldo en JSON para pasarlas a otro equipo. Pensado para el día a día de una persona, desde el celular o el computador. No usa servidor ni cuentas: las tareas se guardan solo en este navegador.

## Ejecución local

Desde esta carpeta:

    python ../dev_server.py

Abrir http://localhost:8080 en el navegador.
