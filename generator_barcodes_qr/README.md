# Generador de códigos QR y de barras

Crea códigos QR (texto, enlace, Wi-Fi, contacto o chat de WhatsApp) y códigos de barras (Code 128, EAN-13, EAN-8, UPC-A, Code 39 e ITF-14). El código se dibuja mientras se escribe, con aviso si algo no sirve, y se descarga en SVG o PNG, se copia o se imprime. También arma una hoja con varios códigos a la vez para imprimir etiquetas. Pensado para quien pone el menú de su negocio en un QR, comparte la clave del Wi-Fi o etiqueta productos y cajas. Nada sale del navegador.

## Ejecución local

Desde esta carpeta:

    python ../dev_server.py

Abrir http://localhost:8080 en el navegador.
